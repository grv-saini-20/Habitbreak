# 🚀 HabitBreak

> Break bad habits. Build consistency. Track real progress.

HabitBreak is a full-stack habit tracking application that helps users eliminate bad habits and build positive routines using streaks, analytics, and daily tracking.

## ✨ Features

- Create and manage habits  
- Streak tracking system  
- Daily progress updates  
- Visual analytics and insights  
- Secure authentication (JWT)  
- Fast and responsive UI
